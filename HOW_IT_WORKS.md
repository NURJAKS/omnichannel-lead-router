## 🔄 Как это работает:

### **1. Клиент пишет в WhatsApp**

```
Клиент → WhatsApp → WhatsApp сервис (Node.js) → CRM API (Python) → База данных
```

**Что происходит:**
1. Клиент отправляет сообщение в WhatsApp
2. WhatsApp сервис получает сообщение
3. Отправляет в CRM через API
4. Бот-менеджер обрабатывает сообщение
5. Сохраняет в базу данных
6. Отправляет умный ответ клиенту

### **2. Автоматические ответы**

Бот понимает:
- ✅ Приветствия ("привет", "здравствуй")
- ✅ Команды ("статус", "помощь", "контакты")
- ✅ Вопросы о ценах, заказах, доставке
- ✅ Регистрацию новых клиентов
- ✅ Общие вопросы

### **3. Сохранение в CRM**

**Что сохраняется:**
- ✅ Все входящие сообщения
- ✅ Все ответы бота
- ✅ История взаимодействий
- ✅ Данные клиентов
- ✅ Сделки и задачи

**Где хранится:**
- База данных SQLite (`crm.db`)
- Таблица `interactions` - история сообщений
- Таблица `clients` - клиенты
- Таблица `deals` - сделки

### **4. Синхронизация с Google Sheets**

**Автоматически синхронизируется:**
- ✅ Новые клиенты → Лист "Клиенты"
- ✅ Новые сделки → Лист "Сделки"
- ✅ Обновления данных

**Как настроить:**
1. Создайте Google Cloud проект
2. Включите Google Sheets API
3. Создайте Service Account
4. Скачайте credentials.json
5. Добавьте в `.env`:
   ```
   GOOGLE_CREDENTIALS_FILE=./credentials.json
   GOOGLE_SHEET_ID=ваш_id_таблицы
   ```

## 🗂️ Структура данных:

```
crm.db
├── clients          # Клиенты
├── deals            # Сделки
├── tasks            # Задачи
├── interactions     # История сообщений WhatsApp
└── sheets_sync      # Синхронизация с Google Sheets
```

### **Google Sheets:**

```
Таблица CRM
├── Лист "Клиенты"   # ID, Имя, Телефон, Email, Компания, Заметки, Создан
└── Лист "Сделки"    # ID, Клиент, Название, Сумма, Статус, Описание, Создана
```

## ⚙️ Настройка:

### **1. WhatsApp (уже работает):**
- ✅ Сервис запущен
- ✅ QR код отсканирован
- ✅ Готов к работе

### **2. Google Sheets (опционально):**

**Шаг 1:** Создайте Google Cloud проект
- https://console.cloud.google.com
- Создайте новый проект

**Шаг 2:** Включите Google Sheets API
- APIs & Services → Enable APIs
- Найдите "Google Sheets API"
- Включите

**Шаг 3:** Создайте Service Account
- APIs & Services → Credentials
- Create Credentials → Service Account
- Скачайте JSON ключ

**Шаг 4:** Настройте таблицу
- Создайте Google Sheet
- Скопируйте ID из URL
- Поделитесь таблицей с email из Service Account

**Шаг 5:** Добавьте в `.env`:
```env
GOOGLE_CREDENTIALS_FILE=./credentials.json
GOOGLE_SHEET_ID=ваш_id_таблицы
```

**Шаг 6:** Установите библиотеки:
```bash
pip install google-api-python-client google-auth-httplib2 google-auth-oauthlib
```

## 🚀 Использование:

### **Для клиентов:**
Просто пишите в WhatsApp - бот автоматически ответит!

### **Для вас (менеджера):**

**Просмотр сообщений:**
- Веб-интерфейс: http://localhost:8000
- Telegram бот: `/stats`, `/help`

**Отправка сообщений клиентам:**
```python
from whatsapp_integration import WhatsAppBotManager
from database import Database

db = Database()
whatsapp = WhatsAppBotManager(database=db)

# Отправить сообщение
await whatsapp.send_client_notification(client_id, "Ваш заказ готов!")
```

**Через API:**
```bash
curl -X POST http://localhost:8000/api/whatsapp/send \
  -H "Content-Type: application/json" \
  -d '{"phone": "79991234567", "message": "Ваш заказ готов!"}'
```

**Просмотр истории:**
- Веб-интерфейс → Клиенты → История
- База данных → таблица `interactions`
