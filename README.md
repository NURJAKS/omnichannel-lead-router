# 🚀 CRM System

Полнофункциональная CRM система с Telegram ботом и веб-интерфейсом.

## ✨ Возможности

- 👥 **Управление клиентами** - добавление, редактирование, поиск клиентов
- 💼 **Управление сделками** - отслеживание сделок с различными статусами
- 📋 **Управление задачами** - создание задач с дедлайнами
- 📊 **Статистика** - общая статистика и аналитика
- 🤖 **Telegram бот** - управление через Telegram
- 🌐 **Веб-интерфейс** - удобный веб-интерфейс для работы

## 📋 Требования

- Python 3.8+
- Telegram бот токен (получить у [@BotFather](https://t.me/BotFather))

## 🚀 Установка

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте файл `.env` на основе `.env.example`:**
```bash
cp .env.example .env
```

4. **Отредактируйте `.env` файл:**
```env
BOT_TOKEN=ваш_токен_бота_от_BotFather
ADMIN_USER_IDS=ваш_telegram_user_id,другой_user_id
DATABASE_PATH=./crm.db
```

### Как получить BOT_TOKEN:
1. Откройте Telegram и найдите [@BotFather](https://t.me/BotFather)
2. Отправьте команду `/newbot`
3. Следуйте инструкциям и получите токен
4. Вставьте токен в файл `.env`

### Как узнать свой USER_ID:
1. Найдите бота [@userinfobot](https://t.me/userinfobot) в Telegram
2. Отправьте ему любое сообщение
3. Он вернет ваш ID - используйте его в `ADMIN_USER_IDS`

## 🎯 Запуск

### Только Telegram бот:
```bash
python main.py bot
```
или просто:
```bash
python main.py
```

### Только веб-интерфейс:
```bash
python main.py web
```
Затем откройте браузер: http://localhost:8000

### Бот + веб-интерфейс одновременно:
```bash
python main.py both
```

## 📱 Использование Telegram бота

1. Найдите вашего бота в Telegram (имя, которое вы указали при создании)
2. Отправьте команду `/start`
3. Используйте кнопки меню для навигации:
   - 👥 **Клиенты** - управление клиентами
   - 💼 **Сделки** - управление сделками
   - 📋 **Задачи** - управление задачами
   - 📊 **Статистика** - общая статистика
   - 🔍 **Поиск** - поиск по базе

### Основные команды:
- `/start` - начать работу с ботом
- `/help` - справка
- `/stats` - быстрая статистика

## 🌐 Использование веб-интерфейса

После запуска веб-интерфейса откройте браузер и перейдите на:
```
http://localhost:8000
```

Веб-интерфейс предоставляет:
- Удобное управление всеми данными
- Визуализацию статистики
- Быстрый поиск и фильтрацию
- Красивый современный дизайн

## 🗄️ База данных

Система использует SQLite базу данных (файл `crm.db`). База создается автоматически при первом запуске.

### Таблицы:
- **clients** - клиенты
- **deals** - сделки
- **tasks** - задачи
- **bot_users** - пользователи бота

## 🔧 Настройка

Все настройки находятся в файле `.env`:
- `BOT_TOKEN` - токен Telegram бота (обязательно)
- `ADMIN_USER_IDS` - ID администраторов через запятую
- `DATABASE_PATH` - путь к файлу базы данных

## 📝 Примеры использования

### Добавление клиента через бота:
1. Нажмите "👥 Клиенты"
2. Выберите "➕ Добавить клиента"
3. Следуйте инструкциям бота

### Добавление сделки:

2. Нажмите "➕ Добавить сделку"

- В боте: нажмите "📊 Статистика" или отправьте `/stats`
- В веб-интерфейсе: перейдите в раздел "Статистика"
